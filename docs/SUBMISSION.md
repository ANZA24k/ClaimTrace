# ClaimTrace

**One-liner:** Verify public claims against complete, committed evidence trails with independent GenLayer consensus and preserved challenges.

**Description:** ClaimTrace prevents moving goalposts and evidence cherry-picking in public statements. Users lock a claim and requirements before committing immutable sources with SHA-256 and byte lengths. GenLayer leaders and validators independently retrieve every source, assess chronology, provenance, consistency and completeness, and ground decisive findings in exact quotations. Deterministic rules return VERIFIED, PARTIAL, CONTRADICTED or INCONCLUSIVE, with contradictions taking precedence. Any actor can add bounded counter-evidence; hash-linked revisions preserve every earlier decision. The public website reads finalized contract state, verifies bytes and receipt chains, exports JSON and submits explicitly reviewed zero-value Studio transactions. Synthetic pilots demonstrate support, contradiction, uncertainty and independent actors. StudioNet is a simulator; hashes authenticate bytes, not truth or authorship.

**Primary tag suggestion:** AI & Agents. Topics: Verifiable Inference, Source Verification, where offered by the submission form.

**How to try:** Open the public URL in DEPLOYMENT.md, inspect the synthetic records and original verdict history, independently verify a source, and open its real explorer transactions. Create a test claim and commit evidence before evaluating, or add new evidence to an open challenge window. Keep the tab open for an ephemeral session account, or use Studio for a retained built-in account.

**What makes it different:** Aggregate contradiction precedence, per-source coverage, fixed pre-evaluation requirements, independently repeated exact retrieval, quote-audited custom consensus and a cumulative, hash-linked public challenge history. The semantic judgment cannot be reduced to string comparison, while evidence integrity and state transitions remain deterministic.
